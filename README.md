# Widget Platform

一个常驻在 Windows 桌面边缘的轻量信息条。想看的模块挂在屏幕边上，鼠标扫一眼就知道状态，需要操作时再展开面板——不用切窗口，也不占桌面。

- **不依赖 WSL2**，普通用户权限运行
- **本地优先**：待办、计时、设置离线可用；某个外部数据源挂了不影响其他模块
- **不编数据**：额度、天气、硬件指标都会标明来源与时间，拿不到就显示不可用，不假装成 0
- **空闲安静**：没有无意义的常驻动画，也没有高频轮询

## 模块

| 模块 | 说明 |
|---|---|
| 待办 | 添加、完成/取消、删除、拖动调整顺序；重启保留 |
| 专注 | 专注 / 休息计时，开始、暂停、重置；睡眠期间照常计时 |
| CPU / GPU / 内存 | 实时占用率与圆环，各自独立的图标与状态 |
| 媒体 | 当前播放的标题、艺术家、封面、进度；上一首 / 播放暂停 / 下一首 |
| Codex | 通过官方客户端只读接口读取额度窗口与重置时间，带来源与新鲜度 |
| 天气 | 当前温度、天气、高低温，以及小时预报折线图 |
| 剪贴板 | 纯文本历史，浏览 / 复制 / 删除。**默认关闭**，需在设置里手动打开 |

模块图标随内容与状态变化（待办显示完成度、计时显示倒计时、天气随天气状况换图标）。图标大小独立于卡片尺寸，空间不够时换行，而不是缩小或裁切图标。

## 安装

从 [Releases](https://github.com/Astyyym/widget-platform/releases) 下载 `Widget.Platform_0.1.0_x64-setup.exe`（currentUser / x64）。

- **未做代码签名**，SmartScreen 可能提示未知发布者，选择「仍要运行」即可
- 需要系统已有 **WebView2 Runtime**（Windows 11 及较新的 Windows 10 通常自带）
- 没有自动更新，升级需手动下载新版本安装包
- 卸载走系统的「应用和功能」，不会留下后台进程

## 使用方法

### 基本操作

| 操作 | 效果 |
|---|---|
| 鼠标移到图标上 | 高亮并弹出概况预览，图标不会位移 |
| 单击图标 | 展开该模块的活动面板 |
| `Esc` | 收起面板，返回摘要栏 |
| 拖动中间的手形手柄 | 停靠到四条边的中心 |
| 点击边缘的三角形 | 收起为一条白色提示条 |
| 点击白色提示条 | 重新显示完整模块条 |

收起只影响显示：后台计时、记录照常运行，草稿也不会丢。

### 停靠与位置

拖动手柄时会显示四条边的虚线目标，鼠标进入哪个就加深哪个；**在目标外松手会保持原来的停靠位置**，不会乱吸附。停靠到左边或右边时，模块条自动转为纵向排列。

### 托盘

应用常驻系统托盘。右键托盘图标：

- **显示主窗口** —— 把模块条找回来
- **退出 Widget Platform** —— 真正停止后台并释放进程

隐藏模块条不会退出应用，只有「退出」才会停掉后台。

### 设置

点击模块条外侧的齿轮打开**独立设置窗口**，分四页：

| 页面 | 内容 |
|---|---|
| 模块与顺序 | 显示 / 隐藏哪些模块，以及它们在条上的排列顺序 |
| 服务配置 | 天气城市与温度单位；可「设为当前位置」主动定位一次 |
| 外观 | 背景材质（普通背景 / 半透明 / 模糊玻璃）、背景透明度、模糊强度、卡片长边与厚度、模块排数（1–4 排）、图标直径 |
| 位置与交互 | 停靠边缘选择，以及隐藏后的唤回入口 |

设置改动即时生效并自动保存在本机，不需要手动点保存。

**关于天气定位**：「设为当前位置」只在点击时获取一次，不会持续追踪；定位失败会保留原有配置。也可以直接输入城市名，重名时会给候选。天气数据缓存至少 30 分钟。

## 数据来源与隐私

- **天气**：数据来自 [Open-Meteo](https://open-meteo.com/)，城市检索来自 GeoNames，均为免费端点，仅供非商业自用
- **Codex 额度**：通过 Codex 官方客户端的只读接口获取，不读取、不保存任何 token 或登录凭据
- **剪贴板**：**默认不采集**。只有你在设置里手动显示该模块后才会开始记录，且只记纯文本；从旧版本升级时会统一停止监听，已有历史不清空
- 所有设置与数据都存在本机，不上传

## 已知限制

- 未做代码签名，首次运行会有 SmartScreen 提示
- 多屏与混合 DPI 下的窗口几何尚未完整验证
- 长时间常驻（24 小时级）的资源表现尚未验证，早期短时测试结果不能代表当前版本
- 跨版本升级没有验证过；同版本重装保留数据是有验证的
- 天气城市检索受上游数据源限制，县级覆盖不完整
- 媒体控制依赖系统 SMTC，并非所有播放器都提供

## 从源码构建

正式产品源码在 `app/`。

```powershell
Set-Location app
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck
npm test -- --run
npm run build
.\run-msvc-rust.cmd cargo test --manifest-path src-tauri/Cargo.toml --locked
.\run-msvc-rust.cmd npm run tauri -- build --no-bundle
```

`run-msvc-rust.cmd` 在进程范围选择 Rust MSVC 工具链并定位 Visual C++ 工具，不修改系统 PATH。换机器前需准备 `rust-toolchain.toml` 指定的 MSVC 工具链、Visual C++ Build Tools、Windows SDK 和 WebView2。依赖版本固定在 `package-lock.json` 与 `src-tauri/Cargo.lock`。

打包安装包在项目根执行 `powershell.exe -NoProfile -File scripts/release.ps1`，会依次跑前端与 Rust 回归、第三方 notice 收集和 NSIS 构建。

### 目录说明

| 目录 | 内容 |
|---|---|
| `app/` | 正式产品源码（Tauri 2 + TypeScript / Rust） |
| `prototypes/` | Goal 1 阶段的技术路线原型，**不是产品入口** |
| `icon/` | 产品图形图标源（43 个 SVG） |
| `designs/` | 已批准的 UI/UX 基线与设计稿 |
| `scripts/` | 构建、检查与打包脚本 |
| `research/` | 第三方参考项目的调研记录（源码副本不随仓库分发） |
